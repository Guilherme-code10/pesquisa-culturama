# 📝 Pesquisa Culturama

Formulário de pesquisa de opinião desenvolvido durante meus estudos de Front-end, com foco na prática de formulários HTML, validação de campos, acessibilidade e estilização com CSS.

## 🚀 Recursos do projeto

- Formulário com dados pessoais
- Campos de perfil e localização
- Seleção de redes sociais e hábitos
- Avaliação da qualidade do serviço
- Campo para opinião do usuário
- Confirmações obrigatórias
- Validações nativas do HTML
- Página de confirmação após o envio
- Estilização de estados válidos e inválidos
- Recursos básicos de acessibilidade

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Formulários HTML
- Validação nativa
- Acessibilidade
- Git
- GitHub

## 📚 Aprendizados

Durante o projeto pratiquei:

- `input`, `select`, `textarea` e `fieldset`
- Tipos diferentes de campos de formulário
- Atributos `required`, `pattern`, `min` e `max`
- Radio buttons e checkboxes
- `datalist`
- Associação entre `label` e campos
- Uso de `aria-describedby`
- Pseudoclasses `:valid` e `:invalid`
- Organização e estilização de formulários com CSS

## ℹ️ Observação

Este é um projeto educacional. O formulário demonstra o envio e a validação no navegador, mas não utiliza um back-end para armazenar os dados.
